# Airbnb-Data-Analysis
# Project Overview
This project analyzes Airbnb listing data to understand pricing trends and room type distribution.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Steps Performed
- Data Cleaning
- Handling Missing Values
- Data Type Conversion
- Exploratory Data Analysis

## Key Insights
- Entire homes are more expensive than shared rooms
- Price varies across neighbourhood groups
- Some listings have very high availability but low reviews
